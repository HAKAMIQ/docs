# HAKAMIQ Docs

Static documentation site prepared for GitHub Pages.

Target URL after publishing repository `HAKAMIQ/docs`:

`https://HAKAMIQ.github.io/docs/`

## Publish

1. Create a public repository named `docs` under `HAKAMIQ`.
2. Upload the contents of this package to the repository root.
3. In Settings → Pages, choose `Deploy from a branch`.
4. Select `main` and `/ (root)`.

The site uses plain HTML/CSS/JavaScript and `.nojekyll`.
