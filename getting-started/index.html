بنية الوثائق

كل قسم له مجلد مستقل ويحتوي ملف index.html. بهذه الطريقة تكون الروابط نظيفة مثل /docs/emulators/.

docs/
├─ index.html
├─ assets/
├─ getting-started/
├─ emulators/
├─ tools/
└─ faq/

إضافة صفحة جديدة

أنشئ مجلدًا جديدًا، ضع داخله index.html، ثم أضف رابطه إلى القائمة الجانبية.

الموقع Static بالكامل، لذلك GitHub Pages يستطيع تقديمه مباشرة.
